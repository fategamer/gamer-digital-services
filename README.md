## Buy flow
1. M-Pesa → Lipa na M-Pesa → Buy Goods
2. Till **6872649**
3. Pay the exact deal amount
4. Send the M-Pesa SMS on WhatsApp **0701 186 627**

Each **Buy** button opens WhatsApp with that deal pre-filled.
